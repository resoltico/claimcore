# Documentation

Start with the task you want to complete:

- [Getting started](getting-started.md): create a fresh synthetic installation and record a case.
- [Case work](case-work.md): find assigned or due work, plan reminders, record narratives and facts, and recover uncertain submissions.
- [People and access](people-and-access.md): add people, handle access requests, update profiles and review roles.
- [Operating](operating.md): host the service, administer authority and databases, and manage retention.
- [Integrating](integrating.md): use HTTPS or CLI, validate results and handle delivery recovery.
- [Contributing](contributing.md): build, choose focused checks and qualify the implementation.

`claimcore help` describes verbs and flags; [OpenAPI](../contracts/openapi.json) owns wire
shapes. [Examples](../examples/README.md) provide independent synthetic request files.
The [workspace examples](workspace-examples.md) show current synthetic screens.
See the [glossary](glossary.md) for terminology and the historical [foundations design](design/foundations.md) for adopted architecture decisions.
