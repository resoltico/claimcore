# Service and CLI contract

Contracts owns [eleven endpoints](../contracts/catalog.json), strict wire codecs and one acyclic
fingerprint. Session is GET; the others are POST to the literal `/api/<endpoint>` path. Session
bootstrap is anonymous; remaining operations require an authenticated actor. API calls carry the
matching fingerprint. Missing or different fingerprints are refused before dispatch. CLI discovery
needs no credentials. Deploy matching service, CLI and browser artifacts.

| Endpoint            | Responsibility                                           |
| ------------------- | -------------------------------------------------------- |
| `session`           | Authentication state, fingerprint and antiforgery token  |
| `session.logout`    | End the browser session                                  |
| `context`           | Runtime context and installation capability advice       |
| `case.preview`      | Advisory review of a business or stewardship act         |
| `case.execute`      | Execute one exact case act                               |
| `case.get`          | Current actor-visible record                             |
| `case.list`         | Actor-visible bounded page                               |
| `case.history`      | Summary or retained full history page                    |
| `operation.observe` | Accepted case or authority evidence visible to the actor |
| `authority.execute` | Register actor, set grant or set enabled state           |
| `authority.list`    | Installation authority review with pagination            |

Case requests carry `operationId`, `caseReference`, integer `expectedRevision` and a tagged `act`.
Authority requests carry `operationId`, `target` principal and tagged `act`. Both use `ACCEPTED`,
`ALREADY_ACCEPTED`, `REJECTED`, `FAILED`, `CANCELLED` and `OUTCOME_UNKNOWN`. A refusal records
nothing. Reads return `SUCCEEDED` or an explicit refusal/failure; observation has no invented
not-found wrapper. Absent and inaccessible resources share `RESOURCE_UNAVAILABLE`.

Schemas close objects and tags and check permanent format invariants. Business admission policy
is evaluated only by Domain on newly asserted values, preserving old accepted text. Strict codecs
reject duplicate members, invalid UTF-8, malformed scalars, invalid UUID/revision values and excess
nesting/bytes. Server responses undergo full schema validation; browser guards check endpoint,
outcome and required consumed shapes. Malformed mutation replies retain exact delivery uncertainty.

Tracked [contract artifacts](../contracts/catalog.json) are generated by F#. Freshness tests check
both inventory and bytes. The fingerprint covers canonical framed catalogue metadata without its
identity field, all schemas, descriptors and default English; derived TypeScript, corpus and the
fingerprint itself are excluded. Generation requires no npm; frontend consumption requires no .NET.

<a id="cc-cli-001"></a>

### CC-CLI-001 — Authenticated frames and exact delivery

The CLI reads `{"endpoint":...,"input":...}` frames over stdin and calls HTTPS with PKCE or
client credentials. It receives no store or database credential. One-line input is one frame;
multiple lines are NDJSON. Frame limit is 128 KiB. Bodies are strict UTF-8 and responses are
validated against the generated contract. Preview is advisory; execution revalidates locked state.

<a id="cc-cli-003"></a>

### CC-CLI-003 — Mutation uncertainty after dispatch

Exit 0 is success; 2 is protocol/business refusal; 3 is definite local/service failure;
4 is dispatched mutation with uncertain delivery; 130 is cancellation. Invocation/root failures
use 64/70. An uncertain retry retains operation ID, expected revision and exact request bytes.
NDJSON stops on 4 or 130; it cannot let a later result mask uncertainty. Host failures carry status,
outcome and dispatch phase. `CONTRACT_MISMATCH` is `NOT_STARTED`; reload before authoring a
different request. No pending request is stored by the service.
