# Architecture and public-contract audit

Audit base: `a742c410e9e26b90e636592e031ba0582179dda3`. The previous domain PR is merged. Existing declarations are reviewed against compiled dependencies and actual callers; the separate [design QA](architecture-contract-design-qa.md) precedes implementation.

| Area | Finding and present decision | Consumers and qualification |
| --- | --- | --- |
| Component graph | Retain the modular monolith, dependency direction, separate witness custody and owner administration. These boundaries protect actual credentials and authority. Twelve product components have explicit roles; no demonstrated defect justifies microservices, a generic dispatcher or merging storage into the host. | Raw/evaluated/compiled graph, ordinary-consumer compiler probes and published dependency closures. |
| Native public facade | The unbound IClaimsCore is publicly exported even though only internal actor composition supplies it. Make that implementation seam internal; IActorClaimsCore is the supported public service facade. | Public compile-positive probe uses actor-bound APIs; an unbound-facade negative probe and reflected surface check reject exposure. Preserve Domain CommandRequest at native admission. |
| Request codec ownership | Web owns fourteen pure JSON request/Unicode/support modules while Contracts owns their schemas and output codecs. Move pure byte decoding and transport DTOs to Contracts; keep bounded HTTP stream reading and Kestrel exception classification in Web. | Web routes remain explicit, bind Drafts once and invoke typed Application. Existing decoder/route tests, new direct codec fuzz coverage and a compiled Web decoder-ownership rule. No framework dependency in Contracts. |
| Export effects | Recovery export signs and registers witnessed custody evidence; runtime admission already treats it as a mutation, but CLI advertises it read-only/cancellable. Treat export as mutating and use mutation cancellation admission in its Web route. | Exact delivery failures remain uncertain; generated CLI input/cancellation contract changes intentionally. A new endpoint still defaults to mutation-safe classification. |
| Outcome knowledge | Native probes show explicit RecoveryMutationUnknown and completed export response loss both return exit 3. Derive failed-outcome uncertainty from Application's typed fault action rather than the outer FAILED tag alone. Do not relabel a successfully issued export as cancelled after Sign completes. | Independent export fault/response-loss/cancellation controls, real custody export tests, published CLI and browser lifecycles. |
| Local export delivery | A verified successful export whose private destination write fails is reported NOT_STARTED. Report RESULT_OBSERVED for that local failure; malformed export replies remain delivery-unconfirmed. | Published authenticated CLI tests exercise the exporter, generated CLI schema validates the additional phase and private-file failure keeps its existing diagnostic identity. |
| Fragmentation and responsibilities | Keep separate authority/recovery/lifecycle contracts and family-specific schema modules. Similar shapes do not establish identical authority or lifecycle. The current flat actor factory is internal, explicitly composed once; replacing it with a generic service bag would add a second abstraction without resolving a demonstrated failure. | No new component, container framework or service registry. Continue inspecting real ports and call sites, rather than splitting code merely for size metrics. |
| Readiness and external authentication | Keep runtime-owned readiness observations and host-owned OIDC discovery parsing. These are distinct from ClaimCore request codecs; moving OIDC into business contracts would conflate protocols. | The decoder ownership rule permits only the explicit OidcAuthority module's third-party JSON boundary, with positive and negative controls. |
| ArchUnitNET acquisition and execution | Retain centrally pinned 0.13.4, PrivateAssets=all, native MTP suite registration and Linux CI. The registry explicitly selects Debug/Optimize=false; loader rejects missing, duplicate, reference and optimised inputs, caches are disabled and reflected types corroborate the loaded model. | Required suite inventory and full CI; ArchUnitNET remains absent from production assemblies. No new test framework or speculative package upgrade. |
| ArchUnitNET rule wiring | ProductTests contains unused copies of deterministic, JSON-writer and time-zone rules that actually run from OwnershipTests. Remove only those demonstrably unregistered copies; retain all executed protections. Add the missing request-decoder ownership rule and a matching fixture. | Exact test registration, qualified bad/good decoder fixtures, existing F# shape controls and architecture report. A green empty selector cannot qualify anything. |
| Architecture manifest admission | The native policy reader accepts duplicate/unknown fields and unsafe project paths. Make its configuration boundary strict, preserving independent graph permissions and test oracles. | Isolated text controls reject unknown fields, duplicate properties, invalid paths and malformed arrays before compiled inspection. Docs remain a presentation consumer; the authoritative architecture gate rejects malformed policy. |
| Generated contracts and runtime | Retain the native AST, generated schema/DTO/validator pipeline, independent wire corpus and explicit HTTP handlers. Changes above update source, artifact lock, tests/inventories, docs and published consumers together. Hashes identify bytes; they do not grant review or replace real-boundary tests. | Complete required verification against one published head; no compatibility loader, baseline migration or live setting change. |

The [ArchUnitNET upstream project](https://github.com/TNG/ArchUnitNET) documents bytecode-based dependency/member inspection and assembly loading. Repository-specific F# controls and actual locked-library execution establish the limits of this wiring.
